HOW TO DEPLOY TO GITHUB PAGES
1. Extract this archive.
2. Upload index.html, manifest.webmanifest and all PNG icons into the root of a GitHub repository.
3. In Settings > Pages, deploy from the main branch / root folder.
4. Open the published URL. On iPad use Safari > Share > Add to Home Screen.

Game modes:
- VS COMPUTER: easy / normal / hard
- TWO PLAYERS: two players on one device
- Arcade Sound: Settings > On / Off
